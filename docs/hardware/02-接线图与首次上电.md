### 烧录/启动经验（已实测）

1. **进入下载模式**：先按住 BOOT，再插 USB（A 转 C），松开 BOOT → COM5 才可被 esptool 识别。
2. **烧录命令**（用户 Python 3.14 + esptool 5.3.1）：
   - `python -m esptool --port COM5 erase_flash`
   - `python -m esptool --port COM5 --baud 460800 write_flash 0 <固件.bin>`
3. **烧完必须手动重启**：这块板 RTS 软件复位无效，烧完仍停在下载模式；
   拔掉 USB，不按任何键，重新插上，MicroPython 才会正常启动。
4. REPL 在 USB-Serial/JTAG 上直接可用（官方固件 USB+UART 双通道），115200 波特率。

## 二、接线图（面包板）

> 面包板原理、内部连通方式和杜邦线类型见 [03-面包板入门与接线详解](03-面包板入门与接线详解.md)。
> 接线需要**公对母**杜邦线最顺手；只有公对公 + 母对母时用文档 03 的"临时接法"。

```
USB-C → 电脑（5V 供电 + 串口）
        │
┌───────┴───────────────┐
│  ESP32-C6 SuperMini   │
│                        │
│ 3V3 ──┬── AHT20  VCC   │
│       └── BH1750 VCC   │
│ GND ──┬── AHT20  GND   │
│       ├── BH1750 GND   │
│       ├── 按键一脚      │
│       └── 继电器 GND    │
│ IO3(SCL) ─┬── AHT20 SCL│
│           └── BH1750 SCL│
│ IO2(SDA) ─┬── AHT20 SDA│
│           └── BH1750 SDA│
│ IO23 ──── 按键另一脚     │
│ IO22 ──── 继电器 IN     │
│ 3V3 ──── 继电器 VCC*    │
└───────────────────────┘
* 继电器供电以模块丝印为准：3.3V 版接 3V3；若标注 5V 版则接 5V。
```

### 逐线对照表

| 模块 | 模块引脚 | 接到开发板 | 说明 |
|------|----------|-----------|------|
| AHT20 | VIN（方形孔） | 3V3 | 3.3V 供电（2.0–5.5V 范围） |
| AHT20 | GND | GND | — |
| AHT20 | SCL | IO3 | I2C 时钟 |
| AHT20 | SDA | IO2 | I2C 数据 |
| BH1750（GY-302） | VCC | 3V3 | 模块板载稳压/上拉 |
| BH1750 | GND | GND | — |
| BH1750 | SCL | IO3 | 与 AHT20 并联同一总线 |
| BH1750 | SDA | IO2 | 与 AHT20 并联同一总线 |
| BH1750 | ADDR | 悬空（默认 0x23） | 若扫不出 0x23，将 ADDR 接 GND |
| 按键 | 任意一脚 | IO23 | 先用 ESP32 内部上拉；电阻到货后改 10kΩ 外置上拉（IO23→10k→3V3） |
| 按键 | 相邻一脚 | GND | 按下接通（读低） |
| 继电器 | VCC | 3V3 或 5V（按丝印） | 模块供电 |
| 继电器 | GND | GND | — |
| 继电器 | IN | IO22 | **低电平=吸合（接通）**，高电平=断开 |
| 继电器 | COM / NO | 今晚不接 | 以后接 12V 灯带或 220V 负载（见安全红线） |

### 面包板布局建议

- 面包板两侧电源轨：一侧走 3V3，一侧走 GND（用杜邦线从开发板引出）；
- 传感器插面包板中间区，用母对母杜邦线接开发板排针；
- 先接好线再上电；**3V3 与 GND 千万别接反**，传感器 VCC 接 3V3 而不是 5V。

> ⭐ **AHT20 认引脚顺序**：模块正面朝自己，从左到右 = **VIN（方形孔）→ GND → SCL → SDA**。
> 方形孔就是 VIN，认准它就不会接反（2026-08-19 实测记录）。

> ⭐ **BH1750（GY-302）认引脚顺序（2026-08-19 实测记录）**：模块插在面包板上、
> 两个圆孔在右边时，**从下往上 = VCC → GND → SCL → SDA → ADDR**（5 脚）。

### AHT20 读数时序（实测通过，2026-08-19）

1. 初始化：写 `0xBE 0x08 0x00`，等 10ms；
2. 触发测量：写 `0xAC 0x33 0x00`，**等 80ms**；
3. 读 6 字节（状态 + 湿度2字节 + 温度2字节 + 校验），读失败就稍等重试，**不要重复触发、不要反复读状态**（实测：反复读状态会导致数据全 0）。

实测脚本：`tools/tests/aht20_read.py`；调试脚本：`tools/tests/aht20_debug.py`、`aht20_textbook.py`。

## 四、OLED 与电阻到货后补充

- OLED（0.96"，SSD1306）：VCC→3V3、GND→GND、SCL→IO3、SDA→IO2，I2C 扫描应出现 **0x3C**；
- 10kΩ 电阻：按键外置上拉（IO23 → 10kΩ → 3V3），替代今晚用的内部上拉。
