## 7. 补充：GitHub 调研可信度评估 + 详细购买清单（2026-10-22 第二次会话）
### 7.1 调研结论
- 验证了所有引用的 GitHub 项目真实存在且未归档：
  - Q_sensor（25★，2026-08 更新，CC BY-NC-SA）：ESP32-C6 Zigbee 多传感器，传感器组合与用户想法几乎一致（AHT20+BH1750+BMP280+QMI8658C 六轴+BS5820 5.8G 雷达），雷达走 IAS Zone occupancy cluster。
  - open-ambient-sensor（41★，2026-10 更新，GPL-3.0）：ESP32-C6 + HLK-LD2410C 雷达，v0.54 已量产验证。
  - BegoonLab/xiao-esp32c6-wifi-sensor（65★）：电池供电+深睡+电池电压监测。
  - andi38/esp-zigbee-sensor-custom-cluster-reporting（1★）：ESP32-C6 自定义 cluster 上报。
  - virsavp/ESP32-Home-Assistant-ir-blaster（6★）：红外发射。
- **BLE+Zigbee 共存可行性**：乐鑫官方支持。
  - ESP-IDF 内置 esp_coex 组件，明确支持 ESP32-C6。
  - 乐鑫官方 issue #316：BLE+Zigbee 崩溃根因是多任务未加锁调用 SDK API，用 esp_zb_lock_acquire/release 解决。
  - 乐鑫员工提供官方测试例程 lpy4105/esp-zigbee-sdk test/ble_zb_light 分支。
- 综合可行性评级：4.5/5。
