# hardware — 硬件方案

第一阶段**零焊接**：全部成品模块 + 杜邦线，按图接线即可。

| 模块 | 数量 | 接口 | 单价参考 |
|------|------|------|----------|
| ESP32-C6 SuperMini 开发板 | 3–4 | — | ≈14 元/块 |
| AHT20 温湿度模块 | 2 | I2C 0x38 | — |
| BH1750 光照模块 | 2 | I2C 0x23 | — |
| SSD1306 OLED 0.96" | 2 | I2C 0x3C | — |
| 5V 继电器模块 / WS2812B 灯带 | 1 | GPIO | — |

第一阶段预算约 120–160 元；PCB 阶段另加 150–250 元（嘉立创 SMT 贴片代工，用户不焊接）。
