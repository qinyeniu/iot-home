## 三、关键风险与对策

1. **Zigbee 天线/组网稳定性**：SuperMini 用陶瓷天线，绝大多数够用；到货后先做"3 块板同屋组网稳定 24h"验收。若频繁掉线，先排查供电与摆放距离，仍不行则换 DevKitM-1 作网关（成本约 +15 元）。
2. **原生 USB 串口**：SuperMini 没有转串口芯片，日志走 USB-Serial-JTAG。固件里必须开启 USB CDC 控制台（`CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`），否则日志只在 UART 引脚上、我看不到。崩溃恢复手法：按住 BOOT 插 USB。
3. **I2C 上拉**：AHT20 / BH1750 / SSD1306 成品模块大多带 4.7k 上拉，同一总线上可能上拉偏强但仍可用；若读数异常，先 I2C 扫描确认地址，必要时裁掉其中一路模块的上拉（焊接/跳线，个别模块有跳线帽）。
4. **3.3V 驱动继电器**：选"低电平触发 + 光耦隔离"的 5V 继电器模块（市面最常见款即可），IO 引脚 3.3V 即可驱动；到货后按验收流程第 7 项实测。
5. **引脚复用（strapping 引脚）**：SuperMini 上 IO4/5/6/7/8/9/15 在启动时有特殊作用，IO12/13 是 USB，IO18/19 接内部 flash。设计引脚分配时只用安全引脚：**IO0/1/2/3/14/20/21/22/23**。

### 购买注意事项（对卖家）

- 认准 **"ESP32-C6 SuperMini"**，别买成 C3 / S3 / H2（外观接近）；到货用 esptool 读芯片 ID 验证；
- 可问卖家一句：板载 **40MHz 晶振**（Zigbee 必需，绝大多数 SuperMini 都有）；
- I2C 模块尽量选自带 4.7k 上拉的成品模块（市面成品多为默认带）；
- 继电器选 **3.3V 逻辑版**（无光耦亦可）：ESP32 只有 3.3V 输出，3.3V 版触发最稳；**光耦只是加分项，非必须**（220V 隔离靠继电器本体）。若选 5V 光耦版，须向卖家确认"IN 接 3.3V 高电平能吸合"。
- 继电器**触点额定必须 ≥250VAC/10A**（切 220V 交流）+ **30VDC/10A**（切 12V 直流）；**不要"固态直流继电器"**（切不了交流）；**别买 12V 线圈版**（3.3V 逻辑驱动不了）。
- 触发**高电平或低电平均可**，固件按实际款适配（下单时让卖家确认触发方式）。
- ⚠️ **220V 安全红线**：220V 只走继电器模块的**螺丝端子**（接成品带插头的线），**严禁上面包板/杜邦线**；接线必须断电操作；初版先用低压 DC 灯泡验证逻辑，220V 演示按后续接线文档执行。
- ⚠️ **零焊接关键点：所有板子和模块一律选"已焊排针 / 带排针（Soldered）"款**。
  默认"裸板"版本排针未焊，到手后无法直接插面包板、也无法插杜邦线，需要自己焊。
  下单时看清规格选项：SuperMini 选"已焊好"；斑梨 C6-Zero 选"Soldered"版；
  OLED / GY-302 / 继电器若有"焊针/不焊"选项，一律选"焊针（已焊）"。
  若某家只有裸板，就换一家（同一商品名基本都有已焊版本）。
