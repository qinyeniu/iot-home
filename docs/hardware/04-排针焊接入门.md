# 04 · 排针焊接入门（给未焊排针的模块装引脚）

> 状态：到货模块（AHT20 / BH1750 / 继电器）均为**未焊排针**版本，需要自己焊上引脚。
> 这是电子制作里**最简单**的焊接类型（通孔焊接），4 个脚几分钟搞定，正好当练手。

## 一、为什么必须焊

排针和模块焊盘之间只有"插着"是不算连接的：金属接触面会氧化、松动，
导致 I2C 时通时断（实测现象：扫描偶尔成功、读数据报 ENODEV）。
焊接 = 用熔化的锡把引脚和焊盘做成**牢固的电气 + 机械连接**。

## 二、需要的工具（约 40–80 元）

| 工具 | 推荐 | 参考价 |
|------|------|--------|
| 恒温电烙铁 | 936 焊台（恒温 350°C）或 60W 内热式 | 30–60 元 |
| 焊锡丝 | 63/37 含铅、0.6–0.8mm（新手好焊，熔点低） | 5–10 元 |
| 松香 / 助焊笔 | 可选，新手友好 | 3–8 元 |
| 烙铁架 + 海绵 | 一般随烙铁附送 | — |

搜索直达：[936 恒温焊台](https://s.taobao.com/search?q=936%20恒温焊台)、
[焊锡丝 0.8mm 含铅](https://s.taobao.com/search?q=焊锡丝%200.8%20含铅)、
[松香](https://s.taobao.com/search?q=松香%20焊接)

> 含铅锡丝最好焊，但烟雾不要吸入（开窗通风）；无铅环保但难焊，新手不推荐。

## 三、引脚方向（关键，先看这里）

你手上的排针**一头短、一头长**：

- **短脚 = 连接模块那端**：从模块**背面**（没有芯片那面）往上穿进孔里，
  让短脚在**正面（芯片面）露出约 1–2mm** 用来焊接；
- **长脚 = 插面包板那端**：留在模块**下方**，焊好后直接插面包板 / 插杜邦线；
- 即模块正面朝上时：上面是芯片 + 短脚头，下面是长脚。

一句话：**短脚朝上穿进模块、焊在正面；长脚朝下垂到面包板。**

> 另一种等效做法：长脚从正面穿过焊盘、焊在背面，最终也是长脚朝下。
> 哪种顺手用哪种，只要最终"长脚在下方、模块芯片朝上"就行。

## 四、焊接步骤（以短脚穿正面为例）

1. **插针**：模块芯片面朝上，把排针从背面伸进 4 个孔，短脚头在正面露出约 1–2mm，
   用手按平或用胶带固定，保证 4 根针垂直、不歪斜。
2. **预热**：烙铁升温到约 350°C，用湿海绵擦干净烙铁头（亮银色为准）。
3. **焊接**（每个脚约 3 秒）：
   - 烙铁头同时接触**焊盘和引脚**加热 1–2 秒；
   - 把焊锡丝送到焊盘与引脚交汇处，锡融化后自然流成一个**小圆锥**；
   - 先移开焊锡丝，再移开烙铁，焊点凝固（约 1 秒，别吹气）。
4. **检查**：4 个焊点应**圆润、光亮**；相邻脚之间**没有连锡**。
   - 连锡了：用烙铁头把多余的锡带走，或用吸锡带/吸锡器处理；
   - 焊点发灰、不亮 = 虚焊，重新加热补一点锡。
5. **冷却** 30 秒，再插面包板。

## 五、安全

- 烙铁头约 350°C：**别碰手、电线、桌面**；不焊时一定放回烙铁架；
- 焊锡丝（尤其含铅）的烟雾**不要吸入**，开窗通风；
- 用完**断电**，烙铁冷却后再收。

## 六、焊完怎么验收

1. 先焊 **AHT20 一块**，插回面包板（VIN 方形孔→+轨、GND→-轨、SCL→IO3、SDA→IO2）；
2. 我跑 `python tools/mp_repl.py COM5 tools/tests/aht20_read.py` 复测；
3. 连续读 3 次都应稳定出数（不再有 ENODEV）；
4. 通过后，BH1750（GY-302，4 脚）和继电器（3 脚）用同样方法焊好再测。

> 所有未焊模块统一处理；OLED 到货后同样操作（4 脚 IIC 成品板若无排针也这样焊）。
