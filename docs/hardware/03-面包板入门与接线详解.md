# 03 · 面包板入门与接线详解

面包板是"插孔即连线"的免焊实验板：不需要焊接，把元件引脚插进孔里，内部金属簧片就把它们接通了。

## 一、内部结构（先懂原理再接线）

面包板孔分两类区域：

```
┌───────────────────────────────────┐
│ + │  a b c d e   f g h i j  │ +   │  ← 上电源轨
│ + │  a b c d e   f g h i j  │ +   │
│ + │ ════════ 中间凹槽 ═══════ │ +   │  ← 凹槽左右不连通
│ - │  a b c d e   f g h i j  │ -   │
│ - │  a b c d e   f g h i j  │ -   │  ← 下电源轨
└───────────────────────────────────┘
```

1. **中间区**：每**一行 5 个孔横向连通**（a–e 是一组，f–j 是另一组）；**中间凹槽把左右分开**（左右不连通，专为芯片跨槽设计）。
2. **两侧电源轨**（通常标 `+` / `-`）：同一竖列上下**纵向连通**，用来统一分配 3.3V 和 GND。注意很多板子的电源轨**中间有断口**（上下半段独立），需要跨断口接线时用公对公线接一下。
3. 结论：**同一行 = 同一个电气节点**；不同行之间要"搭桥"（用公对公跳线）才能连通。

## 二、杜邦线类型（新手最容易混）

| 类型 | 两端形状 | 用途 |
|------|----------|------|
| **公对公** | 两端都是针 | 面包板孔 ↔ 面包板孔（行与行搭桥、行连电源轨） |
| **母对母** | 两端都是套 | 模块排针 ↔ 开发板排针（直连，不走面包板） |
| **公对母** | 一端针一端套 | 模块/开发板排针 ↔ 面包板孔（**面包板接线的"主力"**） |

> 你手上只有公对公和母对母，也能接：把一根**公对公**一头插进面包板孔、另一头翘起来，再用**母对母**把模块排针套到翘起的公头上即可（临时接法）。
> 长期建议补买一小包**公对母**杜邦线（几块钱），面包板接线会顺手很多。

## 三、今晚接线步骤（先单个验证，再加第二个）

**第 1 步：开发板供电到电源轨**

- 公对母（或临时组合）：开发板 `3V3` → 面包板 `+` 轨；开发板 `GND` → 面包板 `-` 轨。

**第 2 步：插 AHT20（跨凹槽，四脚各占一行）**

- 把 AHT20 插在中间区，让四个引脚分别落在不同行（跨过凹槽：左两脚一行组、右两脚另一行组）。
- 公对公搭桥：`VCC 行` → `+ 轨`；`GND 行` → `- 轨`。
- 公对母接开发板：`SCL 行` → 开发板 `IO3`；`SDA 行` → 开发板 `IO2`。

**第 3 步：上电扫描，确认出现 0x38**（先别插 BH1750，降低排错难度）。

**第 4 步：加 BH1750**

- 同样插好，VCC/GND 行接轨；用公对公把 AHT20 的 `SCL 行` 和 BH1750 的 `SCL 行` 连起来（共用一个时钟），`SDA 行` 同理连起来。
- 再扫描：应同时出现 `0x38`（AHT20）+ `0x23`（BH1750）。

**按键**

- 跨凹槽插入，四脚两两相通（同侧两脚是一对）。
- 一侧任一脚的行 → 开发板 `IO23`；另一侧任一脚的行 → `-` 轨（用开发板内部上拉，按下读低）。

**继电器**

- 不用面包板：母对母直连开发板即可（`VCC`→3V3 或 5V 按模块丝印、`GND`→GND、`IN`→IO22）。

## 四、排错口诀

1. 只有**同一行**才连通，跨行要先搭桥。
2. 电源轨如果中间断开，上下半段要分别供电。
3. 先查 3V3/GND（用电表或换孔重插），再查信号线。
4. 一次只加一个传感器，逐个验证。
