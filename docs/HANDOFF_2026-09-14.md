
关键配置：

```c
#define ZB_ONLY_RF_DIAG             0
#define ZB_JOIN_BEFORE_WIFI         1
#define ZB_JOIN_FIRST_TIMEOUT_MS    180000
#define ZB_REJOIN_FIRST_TIMEOUT_MS  180000
#define ZB_TELEMETRY_DEDUP_MS       9000
```

主要能力：

- Zigbee coordinator，固定 channel 26；
- Wi-Fi / 802.15.4 共存；
- Zigbee 回调事件通过 FreeRTOS queue 转到普通任务，避免在调度受限上下文中执行日志或网络操作；
- 使用 NVS 记录组网和节点状态；
- 聚合温度 `0x0402`、湿度 `0x0405`、光照 `0x0400`；
- Wi-Fi 延后到 Zigbee 节点交齐一轮温/湿/光样本后启动，180 秒超时兜底；
- MQTT LWT、retained status、Wi-Fi 断线恢复；
- 同一节点 9 秒内完全相同 payload 去重，打印 `MQTT duplicate suppressed ...`。

节点源码：

## 9. 硬件异常处理原则

- 不要整片擦除 flash；
- 不要擦除 `zb_storage` 或 Zigbee NVRAM；
- 普通 `idf.py flash` 只写 bootloader、分区表和 app，可继续使用；
- 节点本地打印 `DATA:` 不等于上报成功，必须以网关 cached report、MQTT 和数据库为准；
- 如果再次出现纯 Zigbee 都无法入网，优先彻底断电、等待、重插，并尽量直连电脑 USB；
- 串口抓取进程必须按 PID 精确停止，避免误杀当前终端。
