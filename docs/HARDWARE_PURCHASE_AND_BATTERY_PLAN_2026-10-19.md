## 一、旋钮编码器（网关本地控制，必买）

### 1.1 需求
- 用于网关 OLED 菜单本地控制（旋转选择 + 按键确认 + 长按返回）。
- 固件已实现：`iot_rotary_encoder` 组件（PCNT 正交解码），接线 **A=GPIO4、B=GPIO5、SW=GPIO6**，内部上拉已启用。

### 1.2 推荐型号（两种均可）
| 型号 | 说明 | 参考价 | 购买关键词 |
|------|------|--------|-----------|
| **EC11 带按键旋钮编码器** | 裸编码器，20 脉冲/圈，带开关，需外部上拉（可用板内上拉） | 1–3 元/个 | 「EC11 编码器 带开关 20脉冲 手柄」 |
| **KY-040 旋钮编码器模块** | 模块自带 10kΩ 上拉电阻，直接接 3.3V/GND 即可，最省事 | 2–5 元/个 | 「KY-040 旋转编码器模块」 |

### 1.3 推荐：KY-040 模块（省事）
- 接线：
  - 模块 CLK → 网关 GPIO4
  - 模块 DT  → 网关 GPIO5
  - 模块 SW  → 网关 GPIO6
  - 模块 +   → 3.3V
  - 模块 GND → GND
- 无需外部电阻，模块自带 10kΩ 上拉。

### 1.4 若买 EC11 裸编码器
- 需额外买：10kΩ 电阻 ×3（或直接用 ESP32 内部上拉，固件已启用，可不买电阻）。
- 接线：A/B/SW 接 GPIO4/5/6，公共端接 GND。

## 二、电池供电传感器节点（推荐方向）

### 2.1 为什么是传感器节点而不是网关
- 网关同时跑 WiFi + Zigbee + OLED + MQTT，工作电流 80–300mA，电池供电续航极短（18650 也难超一天）。
- 传感器节点用 Zigbee Sleepy End Device（SED），睡眠电流 <20µA，60秒–15分钟周期上报，**才是电池供电的正确场景**。

### 2.2 已有基础
- `firmware/node_battery_sensor`：SED 实验工程，已实现 light sleep、按需 I2C、AHT20/BH1750 上报、poll/采样对齐。
- 尚未烧录实测、未采购专用低功耗硬件。

| 方案 | 电压 | 优点 | 风险 |

### 2.5 低功耗要点（已有设计支撑）
- 启用 Power Management + FreeRTOS tickless + Zigbee light sleep。
- BH1750 用 one-shot 模式（采样后自动断电）。
- AHT20 按需初始化 I2C，采样后释放控制器。
- 未入网时不初始化 I2C。
- 目标：睡眠 <20µA，60s 周期平均约 265µA（理论续航 1000mAh ≈ 157 天）；5 分钟周期平均约 65µA（理论 ≈ 640 天）。
- **必须实测电流**，不能只看理论。

## 六、电池插头说明（补充）

### 6.1 推荐组合（零焊接）
- 锂电池：**3.7V 锂聚合物，带 JST-PH2.0 插头**（红黑线，最常见的锂电池插头）。
- 充电模块：**TP4056 带保护板 + JST 插座 + Type-C 接口**。
- 电池插头直接插到 TP4056 的 JST 插座，无需焊接。

### 6.2 如果只有红黑线（裸线）
- 可以买普通 TP4056（只有 B+/B- 焊盘），把红黑线焊到焊盘或拧紧。
- 需要电烙铁或螺丝端子。

### 6.3 供电链路（重要）
```
锂电池(JST) → TP4056 充电模块 → MT3608 升压模块(调到5V) → SuperMini 5V/VIN 引脚
```
- **禁止**把 3.7V 电池直接接 SuperMini 3V3 引脚（满电 4.2V 会损坏）。
- 必须升压到 5V 接 5V/VIN，或用低静态 LDO 稳压到 3.3V。

### 6.4 淘宝搜索词
- 「3.7V 锂聚合物电池 带 JST 插头 1000mAh」
- 「TP4056 带保护板 Type-C 接口」
- 「MT3608 升压模块」

## 七、供电模块选型详解（升压 vs LDO）

### 7.1 电池已带保护板 → 充电模块可买纯 TP4056
- 电池自带保护板已负责过充/过放/短路保护。
- 充电模块只负责充电管理，买**纯 TP4056 Type-C 充电板（不带保护）**即可（1–2 元）。
- 若想要双保险，买带保护版本也仅多 1–2 元，二者皆可。

### 7.2 模块类型区分（不要买错）
| 类型 | 典型模块 | 功能 | 是否适合 |
|------|----------|------|----------|
| 升压 Boost | MT3608 / SX1308 | 低压→高压，稳压输出 | ✅ 3.7V→5V 路线 |
| 降压 Buck | MP1584 / LM2596 | 高压→低压 | ❌ 无高压源 |
| LDO 线性稳压 | ME6211 / XC6206 | 只能降压，静态电流极低 | ✅ 3.7V→3.3V 低功耗 |

### 7.3 电池传感器节点（推荐）→ ME6211 LDO 模块
- 选 **ME6211 低压差 LDO 模块（输出 3.3V，静态约 30µA）**。
- 优势：静态电流低（睡眠省电）；直接给 ESP32 3V3 供电，绕过板载 LDO（板载 LDO 静态几百 µA）。
- 淘宝搜：「3.7V 锂电池 转 3.3V 稳压模块 ME6211」。

### 7.4 网关临时供电（大电流）→ MT3608 升压模块
- 选 **MT3608 升压模块（输出 5V）**。
- 优势：峰值电流约 2A 撑住 WiFi；输出电压可调；输入 2–24V 宽范围。
- 淘宝搜：「MT3608 升压模块」。

### 7.5 供电链路（按电池节点推荐）
```
锂电池(JST) → TP4056 纯充电板 → ME6211 LDO 3.3V → ESP32-C6 3V3 引脚（绕过板载 LDO）
```
> 低功耗关键：**绕过板载 LDO**，否则板载 LDO 静态电流会显著缩短续航。

## 八、省事方案：18650 电池盒一体充电模块（零焊接，推荐实验阶段）

### 8.1 适用情况
- 找不到充电模块带 JST 插头，或不想焊接。
- 直接买「TP4056 充电 + 18650 电池座 + Type-C + 保护板」一体模块。

### 8.2 购买清单
| 物品 | 规格 | 搜索词 | 参考价 |
|------|------|--------|--------|
| 18650 电池 | 18650 锂电 2000-3000mAh 带保护板 | 「18650 锂电池 带保护板」 | 15-25 元 |
| 一体充电模块 | TP4056 + 18650 电池座 + Type-C + 保护板，输出 5V | 「18650 充电模块 Type-C 带保护板 输出5V」 | 3-8 元 |

### 8.3 供电链路
```
18650 → 一体模块电池座 → 模块输出 5V → SuperMini 5V/VIN 引脚
```

### 8.4 优缺点
- 优点：零焊接、电池可换、容量大、Type-C 充电。
- 注意：模块输出 5V，经板载 LDO 转 3.3V；板载 LDO 静态电流几百 µA，实验阶段可接受。
- 低功耗优化：后续换「锂聚 JST + ME6211 LDO 3.3V 绕过板载 LDO」方案（见第七节）。

### 8.5 两方案对比
| 方案 | 焊接 | 省事 | 低功耗 | 适合 |
|------|------|------|--------|------|
| 18650 一体模块 + 5V | 零焊接 | 高 | 一般 | 现在实验（推荐） |
| 锂聚 JST + ME6211 LDO 3.3V | 需轻焊 | 中 | 优秀 | 后续产品化 |

## 九、实验阶段最终购买清单（确认版）

### 9.1 结论：18650 一体模块已内置升压，无需额外买升压/稳压模块
- 18650 一体充电模块（输出 5V）内部已集成升压电路，直接输出 5V。
- 接 SuperMini 5V/VIN 引脚，板载 LDO 自动转 3.3V。
- **实验阶段不需要买 MT3608 升压模块，也不需要 ME6211 LDO 模块。**

### 9.2 实验阶段只需买 3 样
| 物品 | 搜索词 | 参考价 |
|------|--------|--------|
| 18650 电池（带保护板） | 「18650 锂电池 带保护板」 | 15-25 元 |
| 18650 一体充电模块（输出 5V，Type-C） | 「18650 充电模块 Type-C 带保护板 输出5V」 | 3-8 元 |
| KY-040 旋钮编码器模块 | 「KY-040 旋转编码器模块」 | 5-10 元 |

合计约 30-40 元，零焊接。

### 9.3 何时才需要额外模块
- 后续低功耗产品化（锂聚 + ME6211 LDO 3.3V 绕过板载 LDO）时才需要买 ME6211。
- 网关临时大电流供电才需要 MT3608 升压 5V。
- 当前实验阶段两者均不需要。
