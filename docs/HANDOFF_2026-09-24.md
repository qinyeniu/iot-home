## 2. 用户夜间授权与边界（2026-09-24）

用户准备睡觉，授权 agent 自主进行可把握的更改，并要求：

- 重大更新或无法确认风险的事项留给用户判断；
- 每完成一个部分就提交一次 Git，保障代码安全；
- MQTT 安全部署、TLS/WSS、VPN 暂不执行，等用户有空时由 agent 教学；
- 服务器为**阿里云 ECS**，需要记录并制定后期云服务器配置计划；
- Flash/NVS 断网缓存需重点控制 Flash 磨损；
- 本地配网和凭据管理需要推进，编译时写入不符合产品化；
- 低功耗改造提上日程，后续节点希望支持电池供电；
- 修改前后端代码要慎重；
- 注意留存服务器资源，避免服务器负载或磁盘爆掉。

## 3. 夜间执行红线

1. 不部署、不重启远程服务器；
2. 不修改阿里云安全组、DNS、证书或 VPN；
3. 不切换网卡、不开关热点；
4. 不打开串口、不烧录硬件，除非后续用户另行确认；
5. 不读取、不打印、不落文档任何真实密码文件或凭据；
6. 不整片擦 Flash、不擦 Zigbee NVRAM、不刷 bootloader/分区表；
7. 不使用 `git add -A`。
