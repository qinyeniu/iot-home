- `docs/LOW_WEAR_FLASH_SPOOL_DESIGN.md`

确定方向：

状态：设计完成，未修改分区表，未新增 Flash 写入。

## 10. NVS 产品配置组件复审修复

代码审查提出的问题已处理：

1. 普通 Wi‑Fi 密码上限从 64 改为 63，避免复制到 `wifi_sta_config_t.password[64]` 时没有 NUL；
2. 保存/清除配置使用内部 mutex 串行化，避免多个任务写入造成 SSID/密码混搭；
3. 读取配置时检查 schema version，遇到不支持版本返回 `ESP_ERR_INVALID_VERSION`；
4. 文档明确空 MQTT client ID 表示未配置；后续接入时应传 `NULL` 给 ESP MQTT 以保持自动生成行为；
5. 公共组件 CMake 显式依赖 freertos。
