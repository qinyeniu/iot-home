# HANDOFF 目录：本地长期记忆索引

## 铁律（每次都执行）

**每一次会话结束前 / 每完成一个阶段后，必须把进度、决策、实测结果、待办写入本地交接文档。**

agent 上下文压缩后必然丢失部分记忆，对话记忆不可靠；**本地化文档是本项目保留上下文的唯一可靠方式**。因此每次都要写，哪怕改动很小；项目根目录 `AGENTS.md` 中也固化了同一条铁律。

## 文件规则

- `docs/HANDOFF_YYYY-MM-DD.md`：当天完整交接（新对话的事实来源）；
- `docs/HANDOFF/_YYYY-MM-DD.md`：当天入口摘要（先读它，再按需读完整版）；
- 一天内有多段工作时，更新同一天的两个文件，并在完整版内分节记录。

## 每次会话流程

1. 开工：读本 README → 读最新入口 → 读对应完整交接；
2. 收工：更新/新建当天完整交接与入口 → 显式 `git add` 这些文件 → 提交。
