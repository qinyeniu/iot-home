# 02 · 接线图与首次上电验收

> 状态：OLED 与直插电阻**未到货**；本文档"今晚接线"部分不依赖这两样。
> 引脚草案（到货实测后定稿）：I2C **SDA=IO2 / SCL=IO3**；继电器 **IO22**；按键 **IO23**。

## 一、今晚能做的验收项（第一批到货）

已到货：3×ESP32-C6 SuperMini、2×AHT20、2×BH1750、1×继电器（低电平触发）、按键、面包板、杜邦线、USB-C 线。
未到货：OLED、直插电阻（不影响今晚）。

| # | 验收项 | 需要工具 | 通过标准 |
|---|--------|----------|----------|
| 1 | 上电检查 | USB-C 线 | 电源灯亮，板不烫 |
| 2 | COM 口识别 | 电脑设备管理器 | 插入后出现新 COM 口 |
| 3 | 芯片验证 | esptool | 识别为 ESP32-C6 |
| 4 | I2C 扫描 | 测试固件/脚本 | 同时出现 0x38（AHT20）+ 0x23（BH1750） |
| 5 | 传感器读数 | 测试固件/脚本 | 温度≈室温、湿度合理、光照随遮挡变化 |
| 6 | 按键 | 测试固件/脚本 | 按下读低、松开读高（用内部上拉） |
| 7 | 继电器 | 测试固件/脚本 | GPIO 低电平→咔哒声+模块指示灯亮；高电平→释放 |

> 继电器今晚**不接任何负载**（COM/NO 悬空），只验证控制逻辑；220V 严禁接触。

## 二、接线图（面包板）

> 面包板原理、内部连通方式和杜邦线类型见 [03-面包板入门与接线详解](03-面包板入门与接线详解.md)。
> 接线需要**公对母**杜邦线最顺手；只有公对公 + 母对母时用文档 03 的"临时接法"。

```
USB-C → 电脑（5V 供电 + 串口）
        │
┌───────┴───────────────┐
│  ESP32-C6 SuperMini   │
│                        │
│ 3V3 ──┬── AHT20  VCC   │
│       └── BH1750 VCC   │
│ GND ──┬── AHT20  GND   │
│       ├── BH1750 GND   │
│       ├── 按键一脚      │
│       └── 继电器 GND    │
│ IO3(SCL) ─┬── AHT20 SCL│
│           └── BH1750 SCL│
│ IO2(SDA) ─┬── AHT20 SDA│
│           └── BH1750 SDA│
│ IO23 ──── 按键另一脚     │
│ IO22 ──── 继电器 IN     │
│ 3V3 ──── 继电器 VCC*    │
└───────────────────────┘
* 继电器供电以模块丝印为准：3.3V 版接 3V3；若标注 5V 版则接 5V。
```

### 逐线对照表

| 模块 | 模块引脚 | 接到开发板 | 说明 |
|------|----------|-----------|------|
| AHT20 | VCC（VDD/VIN） | 3V3 | 3.3V 供电（2.0–5.5V 范围） |
| AHT20 | GND | GND | — |
| AHT20 | SCL | IO3 | I2C 时钟 |
| AHT20 | SDA | IO2 | I2C 数据 |
| BH1750（GY-302） | VCC | 3V3 | 模块板载稳压/上拉 |
| BH1750 | GND | GND | — |
| BH1750 | SCL | IO3 | 与 AHT20 并联同一总线 |
| BH1750 | SDA | IO2 | 与 AHT20 并联同一总线 |
| 按键 | 任意一脚 | IO23 | 先用 ESP32 内部上拉；电阻到货后改 10kΩ 外置上拉（IO23→10k→3V3） |
| 按键 | 相邻一脚 | GND | 按下接通（读低） |
| 继电器 | VCC | 3V3 或 5V（按丝印） | 模块供电 |
| 继电器 | GND | GND | — |
| 继电器 | IN | IO22 | **低电平=吸合（接通）**，高电平=断开 |
| 继电器 | COM / NO | 今晚不接 | 以后接 12V 灯带或 220V 负载（见安全红线） |

### 面包板布局建议

- 面包板两侧电源轨：一侧走 3V3，一侧走 GND（用杜邦线从开发板引出）；
- 传感器插面包板中间区，用母对母杜邦线接开发板排针；
- 先接好线再上电；**3V3 与 GND 千万别接反**，传感器 VCC 接 3V3 而不是 5V。

## 三、上电与软件准备

1. 接线检查无误后，USB-C 插电脑（一次只插一块板）。
2. 安装调试工具（我提供命令）：
   - `esptool`（芯片验证/烧录）、`pyserial`（串口读写）；
   - 测试固件两条路线：**快速路线**＝MicroPython（今晚即可 I2C 扫描 + 读传感器）；**正式路线**＝ESP-IDF（约 5GB，本周内装）。
3. 我提供 I2C 扫描与传感器读数脚本，你烧录/接线，我读串口数据一起判断。

## 四、OLED 与电阻到货后补充

- OLED（0.96"，SSD1306）：VCC→3V3、GND→GND、SCL→IO3、SDA→IO2，I2C 扫描应出现 **0x3C**；
- 10kΩ 电阻：按键外置上拉（IO23 → 10kΩ → 3V3），替代今晚用的内部上拉。
