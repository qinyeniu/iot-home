### 11.2 本次完成

修改：

- `firmware/gateway/main/main.c`
- `firmware/common/iot_product_config/iot_product_config.c`

运行时顺序：

1. 启动时先用实验室编译时配置填充 RAM；
2. 只读打开 NVS namespace `iotcfg`；
3. 如果存在 schema version 兼容且字段完整的 Wi‑Fi/MQTT 配置，则 NVS 配置优先；
4. 如果 NVS 未配置、版本不兼容、字段缺失或读取失败，则保留编译时实验室配置；
5. 当前启动读取路径不写入、不擦除 NVS，不增加 Flash 磨损。

其他加固：

- `ZB_JOIN_BEFORE_WIFI=1` 的延迟联网路径也会在启动 Wi‑Fi/MQTT 前完成配置初始化；
- 空 MQTT client ID 会传 `NULL`，保持 ESP-MQTT 自动生成 client ID 的旧行为；
- loader 会将 `ESP_ERR_NVS_NOT_FOUND` 对外归一为 `ESP_ERR_NOT_FOUND`；
- loader 会二次校验 Wi‑Fi SSID 和 MQTT URI 非空；
- 新 namespace/version key 首次保存时能正确创建 schema；
- MQTT 启动日志会遮蔽 URI 中可能出现的 `user:password@`，例如 `mqtt://***@host:1883`。
