# iot_wifi_recovery_policy

Wi‑Fi 恢复策略纯逻辑组件，供网关复用并支持主机测试。

## 职责

- 判断第几次重连重试需要执行 RF 环境扫描；
- 根据扫描成功、空扫描、扫描失败更新恢复证据；
- 判断连续空扫描是否达到深睡恢复阈值；
- 判断冷启动 Wi‑Fi 看门狗应继续等待、重启，还是停止重启。

组件不依赖 ESP-IDF、FreeRTOS、Wi‑Fi 协议栈或硬件，不执行扫描、断连、深睡或重启；这些动作由网关应用层根据返回结果执行。

## 保持的语义

1. retry 为 2、3、4，或 retry >= 8 且每 4 次时，执行环境扫描；
2. 扫描成功：空扫描计数清零，环境存活；
3. 扫描失败：不修改既有环境证据；
4. 空扫描：环境不存活并递增计数，达到阈值时请求深睡恢复；
5. 已连接过、启动宽限期未到：启动看门狗不动作；
6. 周边 AP 可见但目标不可见：不重启；
7. 冷启动且 RF 无环境证据：在重启预算内允许一次 warm reboot；超过预算后继续普通重连。
