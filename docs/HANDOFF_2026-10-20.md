## 3. 焊接指导（已答复用户）
### 3.1 电池盒红黑线 → IP5310
| 电池盒引线 | 焊接到 IP5310 焊盘 |
|-----------|-------------------|
| 红线（电池正极） | **B+** |
| 黑线（电池负极） | **B−** |

### 3.2 输出 → 开发板（还需焊接）
| IP5310 焊盘 | 接到开发板 |
|------------|-----------|
| **OUT+**（5V） | 开发板 5V / VIN |
| **OUT−**（GND） | 开发板 GND |

- 总共焊 4 个点：电池盒红线→B+、黑线→B−、OUT+→5V/VIN、OUT−→GND。
- 六焊盘中两个无标识的 = USB 数据脚/测试点，**不用管**。

### 3.3 安全步骤
1. 万用表确认电池盒红黑线电压 ~3.7V；
2. 先只接电池盒到 IP5310，量 OUT 电压（可能需按键触发输出，应为 5V）；
3. 确认正常后再接开发板；
4. 正负极不可接反；Type-C 口插充电器给电池充电。

## 7. 补充：IP5310 实为 USB-A 口版本（无需焊接）+ 旋钮编码器到货

### 7.1 IP5310 模块确认（2026-10-20）
- 用户实收的 IP5310 模块带 **USB-A 输出口**，**无需焊接**。
- 连接链路（零焊接）：
```
18650 电池 → TP4056 电池盒 →(电池盒红黑线接 IP5310 电池输入/B+/B- 或电池座)→ IP5310 USB-A 5V → USB-A转Type-C线 → 开发板 Type-C
```
- 已更新采购文档第十六节（16.2/16.5）。

### 7.2 KY-040 旋钮编码器到货接线（网关本地控制）
- 固件引脚确认（`local_control.c`）：**A=GPIO4、B=GPIO5、SW=GPIO6**。
- KY-040 接线：
  - CLK → GPIO4
  - DT → GPIO5
  - SW → GPIO6
  - + → 3.3V（不要接 5V）
  - GND → GND
- 模块自带 10kΩ 上拉，无需外部电阻。
- 接线后烧录最新固件（含 local_control）验证 OLED 本地控制界面。
- 已补充到采购文档第十七节。
